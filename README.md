# C Data Structures

Библиотека структур данных и алгоритмов на языке C.

## Описание

Проект представляет собой коллекцию распространенных структур данных и алгоритмов, реализованных на чистом C. Библиотека включает основные структуры данных с полным набором операций для работы с ними.

## Структуры данных

### Dynamic Array (Динамический массив)
Автоматически расширяющийся массив с начальной емкостью 5 элементов.

**Основные функции:**
- `dyn_init()` - инициализация массива
- `dyn_append()` - добавление элемента в конец
- `dyn_insert()` - вставка элемента по индексу
- `dyn_get()` - получение элемента по индексу
- `dyn_replace()` - замена элемента по индексу
- `dyn_del()` - удаление элемента по индексу
- `dyn_find()` - поиск элемента
- `dyn_len()` - получение длины
- `dyn_print()` - вывод содержимого
- `dyn_free()` - освобождение памяти

### Linked List (Связный список)
Односвязный список с операциями добавления и удаления.

**Основные функции:**
- `linked_init()` - инициализация списка
- `linked_append()` - добавление в конец
- `linked_push()` - добавление в начало
- `linked_pop()` - удаление с начала
- `linked_remove_last()` - удаление последнего элемента
- `linked_remove_by_index()` - удаление по индексу
- `linked_print()` - вывод содержимого
- `linked_destruct()` - освобождение памяти

### Stack (Стек)
Реализация стека на основе динамического массива (LIFO).

**Основные функции:**
- `stack_init()` - инициализация стека
- `stack_push()` - добавление элемента
- `stack_pop()` - извлечение элемента
- `stack_peek()` - просмотр верхнего элемента
- `stack_empty()` - проверка на пустоту
- `stack_print()` - вывод содержимого
- `stack_destruct()` - освобождение памяти

### Queue (Очередь)
Реализация очереди на основе динамического массива (FIFO).

**Основные функции:**
- `queue_init()` - инициализация очереди
- `queue_push()` - добавление элемента
- `queue_pop()` - извлечение элемента
- `queue_front()` - просмотр первого элемента
- `queue_back()` - просмотр последнего элемента
- `queue_empty()` - проверка на пустоту
- `queue_print()` - вывод содержимого
- `queue_destruct()` - освобождение памяти

### Set (Множество)
Множество уникальных элементов на основе динамического массива.

**Основные функции:**
- `set_init()` - инициализация множества
- `set_add()` - добавление элемента
- `set_rem()` - удаление элемента
- `set_is_there()` - проверка наличия элемента
- `set_size()` - получение размера
- `set_print()` - вывод содержимого
- `set_destruct()` - освобождение памяти

### Hash Map (Хеш-таблица)
Хеш-таблица с разрешением коллизий методом цепочек. Поддерживает хранение `void*` в качестве значений.

**Параметры:**
- Начальная емкость: 20 бакетов
- Автоматическое расширение при заполнении на 60%

**Основные функции:**
- `map_init()` - инициализация таблицы
- `map_put()` - добавление/обновление пары ключ-значение
- `map_get()` - получение значения по ключу
- `map_print()` - вывод содержимого
- `map_destruct()` - освобождение памяти

### Pair List (Список пар)
Вспомогательная структура для хранения пар ключ-значение (используется в Hash Map).

**Основные функции:**
- `pair_list_init()` - инициализация списка
- `pair_list_append()` - добавление пары в конец
- `pair_list_push()` - добавление пары в начало
- `pair_list_pop()` - извлечение первой пары
- `pair_list_remove_last()` - удаление последней пары
- `pair_list_print()` - вывод содержимого
- `pair_list_destruct()` - освобождение памяти

## Алгоритмы

### Binary Search (Бинарный поиск)
Эффективный алгоритм поиска в отсортированном массиве.

**Функция:**
- `bin_search(int* arr, u64 length, int value)` - возвращает индекс найденного элемента или `NOT_FOUND` (-1)

### Hash Function (Хеш-функция)
Пользовательская хеш-функция для строк.

**Функция:**
- `hash(const char* key, int key_len)` - вычисление хеш-значения для строки

## Использование

### Пример: Dynamic Array

```c
#include "headers/dynamic_array.h"

int main() {
    struct dynamic* arr = dyn_init();

    dyn_append(arr, 10);
    dyn_append(arr, 20);
    dyn_append(arr, 30);

    dyn_print(arr, "%d", "\n");

    int value = dyn_get(arr, 1);  // получить элемент с индексом 1

    dyn_free(arr);
    return 0;
}
```

### Пример: Hash Map

```c
#include "headers/hash_map.h"

int main() {
    struct map* m = map_init();

    int val1 = 42;
    int val2 = 100;

    map_put(&m, "key1", &val1);
    map_put(&m, "key2", &val2);

    int* result = (int*)map_get(m, "key1");

    map_destruct(m);
    return 0;
}
```

### Пример: Stack

```c
#include "headers/stack.h"

int main() {
    struct stack* s = stack_init();

    stack_push(s, 1);
    stack_push(s, 2);
    stack_push(s, 3);

    while (!stack_empty(s)) {
        int value = stack_pop(s);
        // обработка значения
    }

    stack_destruct(s);
    return 0;
}
```

## Особенности

- Использование `typedef unsigned long int u64` для размерных типов
- Автоматическое управление памятью с функциями деструкторами
- Константы для обработки ошибок (`ERROR`, `NOT_FOUND`)
- Hash Map поддерживает `void*` для хранения любых типов данных
- Динамическое расширение структур (Dynamic Array, Hash Map)
